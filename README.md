# منزّل الفيديو (Video Downloader)

تطبيق أندرويد مجاني لتنزيل الفيديو والصوت من يوتيوب وفيسبوك وإنستغرام وتيك توك وX ومئات المواقع الأخرى، مبني على [yt-dlp](https://github.com/yt-dlp/yt-dlp) عبر مكتبة [youtubedl-android](https://github.com/yausername/youtubedl-android).

## التحميل
آخر نسخة دائماً: **Releases → VideoDownloader.apk**

## المزايا
- الصق الرابط أو شارك الفيديو من التطبيق مباشرة فيبدأ التنزيل تلقائياً
- اختيار الجودة: أفضل جودة / 720p / 480p / صوت MP3
- الحفظ في `Download/VideoDownloader` والظهور في المعرض
- تحديث تلقائي يومي لمحرك التنزيل + زر تحديث يدوي

## البناء
يُبنى تلقائياً عبر GitHub Actions عند كل push، ويُنشر الـ APK في صفحة Releases.
